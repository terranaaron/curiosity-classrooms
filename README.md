# Curiosity Classrooms — homepage prototypes

Four creative-direction prototypes for the Curiosity Classrooms website
(Myra Thayer's K-12 science leadership & PD consultancy, Virginia).
Options A–C are each pitched at a different reader: science teachers,
superintendents, and division science leads. Option D folds all three
audiences onto one page and adds a researched service menu — named
packages with per-engagement deliverables (see `docs/service-menu-notes.md`
for the research behind it).

Review site: https://terranaaron.github.io/curiosity-classrooms/

Working drafts — dashed amber boxes mark unconfirmed facts. The Option D
service menu is a proposal awaiting Myra's review. Not a production site.
