# Curiosity Classrooms — homepage prototypes

Three creative-direction prototypes for the Curiosity Classrooms website
(Myra Thayer's K-12 science leadership & PD consultancy, Virginia), each
pitched at a different reader: science teachers, superintendents, and
division science leads.

Review site: https://terranaaron.github.io/curiosity-classrooms/

Working drafts — dashed amber boxes mark unconfirmed facts. Not a production site.
